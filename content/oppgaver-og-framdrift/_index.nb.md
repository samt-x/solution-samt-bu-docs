Oppgavene for selve docs-plattformen ligger som issues i [solution-samt-bu-docs](https://github.com/samt-x/solution-samt-bu-docs/issues) og på brettet [SAMT-BU Docs platform](https://github.com/orgs/samt-x/projects/17) (Project 17). Hvor plattformen skal, står i [Veikart](../veikart/). Denne siden viser hvor arbeidet står.

| Visning | Viser |
|---|---|
| [Board](https://github.com/orgs/samt-x/projects/17/views/1) | Alle oppgaver etter status |
| [By responsible](https://github.com/orgs/samt-x/projects/17/views/2) | Oppgavene gruppert etter hvem som har ansvaret |
| [Open tasks](https://github.com/orgs/samt-x/projects/17/views/3) | Åpne oppgaver i en tabell |
| [My tasks](https://github.com/orgs/samt-x/projects/17/views/4) | Dine oppgaver (krever innlogging) |
| [Timeline](https://github.com/orgs/samt-x/projects/17/views/5) | GitHubs egen tidslinje, uten avhengigheter |

## Tidslinje

Alle oppgavene på brettet, med pilene for hvilke oppgaver som venter på hverandre. Det som har skjedd, er mørkt. Datoer som mangler, er beregnet og stiplet. Figuren lages fra brettet hver time. Slik leser du den, og slik får en oppgave med: se [Tidslinje](/prosjektleveranser/loesninger/samhandlingsplattform/oppgavestyring/tidslinje/) i oppgavestyringen.
